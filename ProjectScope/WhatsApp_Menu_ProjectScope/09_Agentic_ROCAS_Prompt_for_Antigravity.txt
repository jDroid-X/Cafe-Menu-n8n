C = CONTEXT
The reference workflow is:
Incoming message
 -> AI Agent
 -> Gemini LLM
 -> Simple Memory
 -> Google Sheets tools:
    Get Inventory
    Get FAQ
    Post Orders
 -> WhatsApp Send Message

Reference data:
Inventory:
Food Item, Quantity, Status
Orders:
Customer Name, Food Item, Quantity Order, Order Date, Status
FAQ:
Question, Answer

Example menu:
Vada Pav
Misal Pav

Reference behavior:
- "What is available?" lists available items.
- FAQ questions are answered from FAQ data.
- "I want Vada Pav" causes the agent to request missing details.
- A complete order is stored.
- An unavailable item is not accepted as available.
- Agent knows restaurant identity from system instructions.
- Memory retains recent conversation context.
- WhatsApp trigger replaces the initial chat trigger in the final flow.

PHASE 7: BUSINESS RULES
Agent must:
- use configured restaurant name;
- answer from configured FAQ;
- use inventory before confirming availability;
- ask for missing customer/order information;
- save confirmed orders;
- preserve conversation context;
- never fabricate inventory, FAQ or order persistence;
- politely reject unavailable items;
- return a useful fallback when an integration is unavailable.

PHASE 8: SECURITY
Never expose raw API secrets in the UI.
Use secret references or environment variables.
Mask secrets.
Do not log tokens.
Do not import credentials from any downloaded reference workflow.

- Do not reuse its production credentials.
