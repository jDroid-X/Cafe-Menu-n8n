5.3 REFERENCE VIDEO FLOW
The source demonstrates an initial On Chat Message trigger, AI Agent, Gemini Chat Model, Simple Memory, Google Sheets tools, restaurant system instructions, then replacement of the initial trigger with WhatsApp Business Cloud On Message and connection to WhatsApp Send Message.

5.4 TOOL DEFINITIONS
GET INVENTORY
Input: food item or availability query.
Output: matching menu/inventory rows.

GET FAQ
Input: customer question.
Output: configured FAQ answer.

POST ORDERS
Input: customer name, food item, quantity, status, current timestamp.
Output: saved order confirmation.

5.5 ORDER FLOW
Customer: "I want Vada Pav"
 -> Agent asks quantity/name if missing
 -> Customer provides details
 -> Agent checks availability
 -> Agent records order
 -> Agent confirms order

5.6 UNAVAILABLE ITEM FLOW
Customer requests unavailable item
 -> Inventory tool returns unavailable
 -> Agent refuses confirmation
 -> Agent offers currently available options

5.7 MEMORY FLOW
Message 1: customer gives name
Message 2: customer orders
 -> Memory provides context
 -> Agent avoids asking for already-known details where valid.

5.8 ERROR PATH
Any integration error
 -> Capture error
 -> Mark operation failed
 -> Produce truthful fallback
 -> Log event
 -> Do not fabricate success.
